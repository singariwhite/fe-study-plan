# 基本情報技術者試験：2026年12月20日 合格ロードマップ

## 使い方
- `index.html` だけで動く、スマホ対応の勉強管理ページです。
- ブラウザで開くと、今日やること・時間配分・到達目標が表示されます。
- 記録は使用中のブラウザのlocalStorageに保存されます。ブラウザが違うと自動同期されません。
- 右上の「使い方・保存」で進捗JSONをエクスポート・インポートできます。

## Webで公開する手順（GitHub Pages）
1. GitHubで新しい公開リポジトリを作る（例：`fe-study-plan`）。
2. GitHubの `Add file` → `Upload files` で `index.html` をルートへアップロードしてコミットする。
3. `Settings` → `Pages` → `Build and deployment` → `Source: Deploy from a branch` → `Branch: main / (root)` → `Save`。
4. 公開後は `https://ユーザー名.github.io/fe-study-plan/` のようなURLでアクセスできます（実際のURLはPages設定画面で確認）。
5. iPhoneのSafariでページを開いて「共有」→「ホーム画面に追加」にすると使いやすいです。

※ Webへの公開操作そのものはまだ行っていません。GitHub Pagesは原則公開サイトなので、個人情報は書かないでください。
※ 学習記録はブラウザ内保存なので、同じiPhoneのSafariで閲覧すれば引き続き利用できますが、消去した場合は復元できません。時々JSONを保存してください。
